# 1.1.0.0-beta

日期：2026-09-27。基于 r10 启动验收形成的早期测试版源码，面向 Windows x64 便携 Launcher；保留 Docker 部署与 MIT 许可。

## 本版内容

- C# / Avalonia 自包含 Launcher，集成独立 PostgreSQL、Python Web 与浏览器运行时，不依赖 Docker。
- UI、无界面验收和真实 Host 复用 Core 的统一启动用例；初始化与业务数据库准备作为独立步骤，停止、重启、端口切换保留身份核验和回滚保护。
- 持久启动日志、无 Host 时可用的诊断预览和脱敏导出；启动失败可先查日志，不必重新打包才能排障。
- [增量开发及真实启动链路验收](LAUNCHER_DEVELOPMENT.md)，复用只读组件和隔离合成实例。
- 普通暂存、构建和交付产物继承项目权限，数据库口令与控制令牌继续单独保护。

## 已有验收证据

r10 在本机普通非管理员账户、中文解压路径下，使用实际自包含 EXE 通过首次初始化启动、停止后同窗口重启、运行中安全退出、重开后手动启动。实际 PG/Python 进程和 `/health` 就绪可核验，验收结束未留下受管进程；原生诊断界面的滚动与底部按钮已检查。

此前源码回归通过 Core、HTTP 契约、Python 生命周期、Windows 进程、真实 PostgreSQL、包 Host、离屏 UI、端口避让和进程接管测试。这些结果各有范围，不能替代完整业务验收。

## 已知限制

- 尚未完成无开发工具的干净 Windows、完整闲鱼登录/抓取/AI/通知流程、DPI 矩阵及最新冻结源码的 Docker 回归。
- 备份恢复曾出现独立串行验收失败，稳定性根因未完全确认。不要将此 beta 的备份恢复作为唯一数据保障；不要覆盖已有生产实例或导入唯一业务数据副本。
- 本机启动验收未创建管理员、未启动真实监控任务，也未调用付费 AI 或发送通知。
- 仅交付 Windows x64 桌面路线；不承诺 macOS/Linux 桌面包、自动升级或完整发行放行。
